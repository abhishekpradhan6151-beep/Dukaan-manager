    The balance is the total of the ledger entries. It cannot be typed over. Entries are never deleted; a correction is a new entry. A repayment, once saved, cannot be reversed in this version.

    Expenses

    How to read this: Sales is the value of bills made. Money received is separate: it includes customer repayments, which are never counted as sales.     Settings & Backup

    Shop details (printed on receipts)

    A new prefix applies to new invoices only. The number keeps counting up and never repeats.

    Backup & restore

    A backup is a file copy of all your shop data (products, stock, sales, customers, udhaar, repayments, expenses and settings). It is saved to this device only. Nothing is uploaded and there is no automatic or cloud backup.

    • Download a backup regularly, and before restoring or clearing browser data.
    • Copy the file to another place you control (a pen drive, another computer, or your own cloud storage).
    • The file is not encrypted and contains customer names, phone numbers and business figures. Keep it private.

    Restore from a backup

    Restoring replaces all current data on this device with the file’s data. It is never merged. If the restore fails, your current data is kept.
